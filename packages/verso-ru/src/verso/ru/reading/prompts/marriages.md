<!-- Выжимка правил извлечения браков. -->
Запись о браке (часть вторая метрической книги, «о бракосочетавшихся»).

Поля записи:
- `record_num` — номер записи;
- `w_day`, `w_month` — день и месяц венчания;
- `groom_age`, `bride_age` — возраст жениха и невесты;
- `groom_marriage_num`, `bride_marriage_num` — каким браком («первымъ», «вторымъ» → «1», «2»),
  только если это написано.

Персоны (`slot`):
- `groom`, `bride` — жених и невеста;
- `witness` — поручители, по порядку записи (по жениху, затем по невесте);
- `relative` — названные родственники (отец жениха, отец невесты, …). `relationship` — кем он приходится
  тому, при ком назван (`father`, `mother`, `son`, …), `relationship_of` — при ком: `groom`, `bride` или
  поручитель с номером по порядку записи (`witness 1` … `witness 6`); null, если запись не говорит, при ком.
  «Отец невесты» — `father`, `bride`; «сын первого поручителя» — `son`, `witness 1`. `relationship` — null, если
  персона не `relative` или подходящего кода нет (брат, …); `relationship_of` — null у всех, кроме `relative`;
- `priest`, `deacon`, `dyachok`, `sexton` — причт, если назван.
