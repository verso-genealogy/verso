# Security

**English** · [Русский](SECURITY.ru.md)

## Supported versions

verso (verso-core, verso-ru) is at 0.x: only the latest 0.x release receives fixes.

## Reporting a vulnerability

Report it privately through GitHub — **Report a vulnerability** on
https://github.com/verso-genealogy/verso/security/advisories/new — not as an issue. You will get an
answer within a week; a fix and an advisory follow once the report is confirmed.
