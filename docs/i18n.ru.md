# Язык интерфейса

[English](i18n.md) · **Русский**

verso говорит с человеком — ошибка, справка команды, находка линтера — через каталоги сообщений, по
одному на язык. Исходный язык — английский; русский — перевод. То, что verso *порождает* — текст
профиля Geni, CSV Familio, хронологию, — не интерфейс и никогда не следует его языку.

## Какой язык

В таком порядке:

1. `verso --lang LANG <command>` — для этой команды;
2. `VERSO_LANG`, заданная для команды;
3. `[i18n] locale` в `verso.toml` (схема 5); файл схемы 4 или более старой говорит по-русски, как говорила
   библиотека до каталогов, а файл схемы 5 без этого ключа говорит по-английски;
4. английский.

Системные `LANG` и `LC_*` ничего не значат. Без рабочего пространства — при ошибке, которая говорит,
что его не нашли, — язык берётся из `VERSO_LANG`, иначе английский. Язык, которого никто не поставляет,
отвергается со списком языков.

```toml
schema = 5

[i18n]
locale = "ru"
packs = []          # language packs to enable, by name
```

## Каталоги

Каждый дистрибутив поставляет свои каталоги как данные пакета, `<package>/locales/<lang>.toml`:

```toml
schema = 1
untranslated = []              # in a translation: the keys still printed in English

[workspace]
not_found = "no workspace found from {start}"

[plugins.count]                # a plural: a table of CLDR categories, chosen by `count`
one = "{count} plugin"
other = "{count} plugins"
```

- Ключ — это `<module>.<what>` внутри своего пакета (`workspace.not_found`); ключ линтера — его код
  и вариант (`CPL002.no_father`).
- Параметр — это `{name}`; буквальная фигурная скобка — `{{` или `}}`.
- Ключ, которого нет в языке, берётся из английского; если ключа нет и в английском, каталог не
  читается или параметра не хватает, печатается `key {params}`. Вывод никогда не бросает исключение:
  ошибка, ради которой создано сообщение, никогда не скрывается его сообщением.
- Код вызывает `t("key", name=value)` из модуля `messages` своего пакета. Это возвращает `Message`,
  текст которого собирается при чтении, на языке этого момента.

Ключи каталогов и их параметры публичны: перевод пишется против них.

## Языковые пакеты

Язык, которого verso не поставляет, приходит отдельным дистрибутивом: точка входа группы
`verso.locales` даёт `verso.core.i18n.LocalePack` — его имя, язык, каталог для каждого пакета
(`"<import package>:<path>"`) и правило множественного числа, — а рабочее пространство включает его
по имени в `[i18n] packs`. Языковой пакет не может заменить язык, который уже поставляет какой-либо пакет. Языковой пакет,
который не установлен или заменил бы поставляемый язык, и `locale`, на котором никто не говорит,
отвергаются, когда читается `verso.toml`; до этого сообщение берётся из английского, а языки, которые
поставляет пакет, к языковым пакетам не обращаются. `VERSO_LANG` или `--lang` с языком, на котором
никто не говорит, отвергаются при запуске `verso`.

## Что не переводится

Текст книг бывает четырёх видов, и интерфейсу принадлежит только первый:

- **сообщения** человеку — через каталоги;
- **порождённое содержимое** — проза Geni и её ключи локалей, CSV и справочник Familio, хронология:
  профиль содержимого плагина, замороженный, на каком бы языке ни говорил интерфейс;
- **словарь источников** — статусы, причины смерти, святцы, старая орфография: принадлежит плагину,
  на языке книг;
- **предметная область книг** — пол, обозначение листа, имения: принадлежит плагину, а не ядру.
