# Безопасность

[English](SECURITY.md) · **Русский**

## Поддерживаемые версии

verso (verso-core, verso-ru) в версии 0.x: исправления получает только последний релиз 0.x.

## Как сообщить об уязвимости

Сообщите о ней приватно через GitHub — **Report a vulnerability** на
https://github.com/verso-genealogy/verso/security/advisories/new — а не в issue. Ответ придёт в течение
недели; исправление и advisory последуют, когда сообщение подтвердится.
