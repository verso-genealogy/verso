# Как участвовать

[English](CONTRIBUTING.md) · **Русский**

```sh
pip install -e "packages/verso-core[schema]" -e "packages/verso-ru[xlsx,dsl-tools]"
python -m pytest tests                       # тесты библиотеки
python -m pytest -p tests.core.block tests/core   # одно ядро, с заблокированным verso.ru
ruff check . && pyright
python -m tools.reference --check            # справочник актуален
```

- **Тест к каждому изменению.** Изменение поведения приходит с тестом, который без него падает;
  исправление — с тестом, который воспроизводит ошибку. Тесты читают только свои фикстуры —
  синтетический корпус в `tests/fixtures/` — и никогда не настоящий.
- **Фасад DSL, JSON записей, команды, ключи рабочего пространства, коды линтеров** публичны
  ([совместимость](docs/compatibility.ru.md)): изменение любого из них — пометка в примечаниях к
  релизу, а удаление проходит через объявление устаревшим.
- **Выходные данные, которые служат адресами** — res_names, идентификаторы записей — остаются
  неизменными по байтам; изменение их написания — это новый профиль или новое правило, а не правка.
- **Сообщения** пользователю — находки линтеров, ошибки — следуют [правилам i18n](docs/i18n.ru.md):
  английский — исходный язык (`locales/en.toml`), русский — перевод (`ru.toml`); содержимое — слова
  самих записей — никогда не переводится. Код и комментарии — на английском.
- **Документация** пишется на английском, это исходник. У руководств в `docs/`, README, README
  примера, этого файла и SECURITY рядом лежит русский перевод (`X.ru.md`), который меняют в том же PR;
  `tests/repo/test_public_texts.py` проверяет, что у них одни и те же заголовки, таблицы, код и
  команды. Справочник (`docs/reference`) собирается из кода и остаётся на английском.
- **Как проверяется изменение.** `make premerge` запускает все проверки. Неизменность по байтам на
  настоящем корпусе проверяет мейнтейнер при релизе. PR, который меняет то, что производит корпус
  (Terraform, CSV, JSON записей, отпечатки храповиков), говорит об этом в описании.
